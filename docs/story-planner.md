# 单作家剧情规划

在「规划 → 剧情规划」启用功能并刷新。选择已在 API 设置创建的独立文本模型，可填写创作偏好。旧规划模型绑定沿用。正常游玩无需看稿或批准。

第一次符合条件的正文请求等待作家发布全局与章节札记。之后读取当前章节定稿。已确认的章节边界改变，或作家登记的关键世界字段、剧情记录发生变化，才重新审稿。篇目收束不单独触发。全局前提仍适用时只更新章节稿。作者可全视后台，章节稿按写手可见范围成稿，正文只读该稿全文。独立更新、聊天原文、总结与召回不写入创作稿。

版本保存在当前客户端 IndexedDB，按账号、聊天和世界分支隔离，附楼层来源摘要与世界版本。编辑、回退或切换聊天时重新核验来源。札记预算为传入上下文上限的四分之一，无法容纳时整段略过。独立模型失败时正文继续，在规划页点击「下次正文重试」可以解除本次审稿的失败抑制。模型措辞可能暗示未揭露事实，需通过实际游玩评估。后台验收命令为 `node --import tsx --test modules/story-planner/planner.test.js modules/story-planner/host.test.js`。

后台提示词明确处理三种偏离：离场后线索留在原处，另辟路线按现有资源与条件判断，提前查明的事实立即更新人物知情范围。
