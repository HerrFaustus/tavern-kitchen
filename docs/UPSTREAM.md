# 来源与修改说明

Based on LittleWhiteBox by biex.

- 上游：<https://github.com/RT15548/LittleWhiteBox>
- 固定提交：`e30ebadf69cd53e9fafc5f81f74b9499911f78f5`
- 上游版本：3.2.2；派生版：酒馆后厨 0.2.1。
- 修改日期：2026-10-30。
- 原始快照保留在外层 `references`，不在原始快照上修改。

主要修改：物理删除无关模块与领域模型；缩减 OS host/shell 两端注册表；拆除骰子经济和付费重掷；保留人物属性编辑与已掷结果的确认保存；把配置、文件、数据库和主要全局入口改到后厨命名空间；以精简扩展设置替换原总控页；拆出 API 配置存储；调整构建入口、依赖、测试与独立目录的宿主路径解析；禁用并移除上游自动更新。

`shared/legacy-markup` 的三个解析器来自上游绘图／语音模块，保留纯文本清洗用途。`modules/streaming-generation.js` 属于模型调用适配层，记忆跟随酒馆 API 时仍需要它。

原有源码中的部分类型名、路径、`xb` 指令以及内部标识仍保留，以避免本次删减引入不必要的协议迁移。文件版权依照原始上游；上游许可证和附加声明保持原文。详细删除路径见 `v1-removed-files.json`。

0.1.1 参考柏宝书固定快照 `0a3a1cdfe92bf5ff1b822b6b6588cb694090d0da` 的 `src/topbar.ts`，采用宿主 `#top-settings-holder`、`.drawer` 与 `.drawer-icon` 接入方式。厨师帽 SVG、统一标签工作台、嵌入接口与主题桥接为本次新写实现；未复制柏宝书业务代码。原有记忆、规划、变量和 OS 页面改为嵌入同一工作台，数据格式与消息校验保持原有机制。

0.1.2 将一级导航收敛为记忆、规划、设置，把原记忆设置与模型接口归入设置。参考柏宝书 `floorPanel.ts`／`FloorPanel.vue` 的楼层下方摘要交互，新写 `modules/story-summary/floor-summary.js`；按后厨已提交批次的实际范围展示摘要，不移植柏宝书的数据写回或生成逻辑，也不新增模型调用。

0.1.3 新增“世界”一级分区，人物、关系、局势与设定、变量、地图、后台演化集中于此；事件时间线保留在记忆。外观增加默认跟随酒馆选项，沿用既有主题存储并保留手动选择；人物名单与档案导航适配分区和窄屏。未改动现有世界事实或记忆数据结构。

0.1.4 解除面板打开时的聊天门槛，保留聊天数据操作的绑定校验；共享 Agent 设置改用后厨 AgentApiStorage，修复默认动态导入旧存储导致的 get 报错。统一 OS 页面的宿主主题、字体、控件及返回导航，移除已删除短信模块的残余样式引用和世界页随机外部装饰图。

0.1.5 将后厨内容移入原生 drawer-content，优先调用宿主公开的 doNavbarIconClick；缺少该导出的 Tavern 宿主使用兼容类切换。同步宿主关闭状态，保留固定抽屉，新增桌面展开宽度与减少动画支持。嵌入工具移除底部系统导航，按当前返回栈显示顶部返回；Esc 收起不卸载共享页面。主题桥新增宿主字号，表单字体统一继承。

0.1.6 将人物档案和关系图合并在“人物与关系”，旧 relations 路由兼容转向 people；记忆一级标签及关联入口改称剧情。入口移至 persona-management-button 之后、rightNavHolder 之前。工作台采用 fillRight 右侧布局和水平滑入，窄屏全宽；保持宿主开合行为及已有存储键。

0.1.7 移除自绘厨师帽 SVG，使用宿主 Font Awesome 的 fa-door-open；移除展开工作区及横向动画，右侧面板桌面贴顶、按高度向下展开。导航按钮使用 menu_button/active，移除重复着色背景，跟随宿主文字阴影。人物与关系入口简称人物。局势与设定基于既有事实属性做互斥只读分组，关系事实及已撤销记录不进入这两个视图，重点保留标志不参与分类。

0.1.8 拆分轻量同步入口与异步功能运行时，恢复被重建的宿主工具栏入口；世界前置并作为首次默认页。统一所有嵌入页跟随宿主主题，删除主题选择器与 Neo 样式资源，忽略旧主题键。控件双向过渡统一采用宿主时长，移除仅进入时播放的页面与表单动画；关系图响应宿主主题变化。

0.1.9 删除内置使用说明、HF 部署指南、规划流程教程及专用样式。通过宿主原生控件计算样式统一嵌入按钮、表单与分组标题，去除独立卡片装饰；规划页改用顶部按钮导航，地图与骰子改用原生复选框并保留异步保存语义。

## 0.2.0

新增后厨自己的 world-records 模块：独立实体和来源映射、事务命令、历史分支、IndexedDB 适配器与原生管理面板。沿用小白X已确认记忆与地图服务的只读数据，通过变更通知建立候选记录；不替换原来源的存储、提示词注入或变量写入。

## 0.2.1

世界默认进入只读总览；移除独立档案导航，旧链接仍兼容。新增、修订、交易和备份归入设置的世界管理，两页共用既有状态内核与存储。局势使用独立外层路由，剧情 iframe 的旧 world 视图保持兼容。没有新增模型调用或迁移旧数据库。
