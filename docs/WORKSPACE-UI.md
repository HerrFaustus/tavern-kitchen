# 酒馆后厨工作台界面约定

本工作台延续 SillyTavern 的原生视觉体系。参照柏宝书的顶部工具栏入口方式，使用宿主门形图标标识后厨；此文记录 0.2.1 的宿主集成约定，不另建全局配色或字体体系。实现以 `core/kitchen-workspace.js`、`core/kitchen-embedded.css`、`style.css` 与各模块挂载代码为准。

## 宿主主题与入口

- 后厨入口使用宿主 `fa-solid fa-door-open fa-fw`；入口沿用 `drawer` / `drawer-toggle` / `drawer-icon` 结构，插入 `top-settings-holder` 内、`persona-management-button` 之后、`rightNavHolder` 之前。宿主尚未生成工具栏时等待插入；没有角色管理入口时追加到工具栏末尾。
- 所有后厨页面固定跟随酒馆主题，用 `tk-follow-host` 统一配色、字体、透明度和动效。移除主题选择器、快捷切换器及 Neo 样式资源；不再读取 `xb-theme-alt`。该旧键不删除，以免影响同时安装的原版小白X。外观页只说明在酒馆外观设置中调整。
- 跟随宿主时，文本、次要文本、强调、边框、面板背景与悬停背景分别使用 `SmartThemeBodyColor`、`SmartThemeEmColor`、`SmartThemeQuoteColor`、`SmartThemeBorderColor`、`SmartThemeBlurTintColor`、`SmartThemeChatTintColor`。嵌入字体继承宿主；默认色仅作缺失变量时的回退。
- 嵌入页按钮、输入框与分组标题读取宿主 menu_button、text_pole、standoutHeader 的实际计算样式；默认、选中和禁用分别采样，配色、字体、边框、圆角及内边距跟随宿主。原生控件样本隐藏且不可交互，不增加可见入口。
- 工作台使用边框和背景区分层次。选中标签通过原生 menu_button.active 状态及加粗标识，键盘焦点保留可见轮廓；不以固定品牌色覆盖用户主题。

## 共享面板与导航

一个非模态面板承载四个一级标签，顺序固定为世界、剧情、规划、设置。面板作为后厨 drawer 的 drawer-content fillRight 在右侧从顶端向下展开，无遮罩或焦点锁定；功能内容在面板内部滚动。二级入口以 `KITCHEN_ROUTES` 为准：

| 一级标签 | 二级入口（路由） |
| --- | --- |
| 世界 | 总览（`world`）、局势（`situation`）、设定（`lore`）、人物（`people`）、变量（`variables`）、地图（`map`）、后台演化（`world-engine`） |
| 剧情 | 事件时间线（`memory`） |
| 规划 | 剧情规划（`planner`）、行动判定（`dice`） |
| 设置 | 功能开关（`settings`）、剧情设置（`memory-settings`）、模型接口（`agent-api`）、世界管理（`world-management`） |

- 剧情聚焦事件时间线。旧记忆页的人物、关系及世界事实分入“世界”，变量和地图也归入此组；“局势与设定”展示原有 facts，“后台演化”进入原 OS 世界功能，两者不混用。
- 剧情设置仍归入“设置 → 剧情设置”；原记忆页设置按钮（`archive-manage-open`）在嵌入模式隐藏，助手和数据管理入口仍复用设置视图并切换到对应内部页面。剧情规划保留在独立的“规划”一级标签。
- 后厨门形按钮切换展开/收起，并维护 `aria-expanded`。首次默认进入世界的总览页，后续展开恢复当前路由；点击一级标签进入该组首项。展开时把焦点交给所属一级标签；收起恢复到打开前仍存在的焦点元素，否则返回后厨门形按钮。
- 一级导航使用 `tablist`、`tab`，共享内容区为 `tabpanel`，并关联当前一级标签；当前标签是唯一 `tabindex="0"`。左右方向键循环切换并激活，Home/End 转到首尾。二级入口使用普通按钮及 `aria-pressed`，同组切换不重建按钮，以保留焦点。
- 面板收到未被处理的 Escape 时收起；共享 OS iframe 内的 Escape 先消费详情或弹层返回，根页面再通知宿主收起。记忆、规划 iframe 的局部快捷键仍由各模块处理。切换聊天重置并收起工作台。离开变量路由或收起面板停止其观察器。
- `openKitchenTab()` 按当前路由自动选中所属一级标签；原变量、地图等入口保留。注意 `world` 指世界总览，`situation` 指局势；旧 `world-records` 转到总览，OS 世界入口改用 `world-engine` 并映射到原 OS `world` 应用。扩展设置中的“打开酒馆后厨”和消息操作区“剧情总结”入口继续保留。

## 世界与总览

世界栏目表示整个横向世界状态；人物、局势、设定、变量和地图是分类视图，后台演化是运行机制。总览汇总同一状态的对象、事实、待处理数量及近期变化，无独立存储或 AI 调用。新增、修订、交易与备份归入设置的世界管理。代码仍以 world-records 命名内核，保留既有数据库以兼容存档；分类页的权威数据接管尚在进行。

总览与世界管理使用独立原生 DOM 挂载点，共用同一个服务和存储。旧剧情 iframe 内部的 world 视图仍表示局势，宿主桥将其映射到外层 situation，防止内部切换误开总览。

## 模块边界与状态

- 记忆、规划与共享 OS 内容保持同源 iframe 边界，以隔离文档样式和全局变量；这不是安全沙箱。主题桥在加载后注入嵌入样式，复制宿主颜色与阴影变量、字体、字号和动效时长，并观察宿主根节点、body 的 class/style/data-theme 变化；卸载时断开观察器。
- 事件时间线、局势与设定、人物、关系及剧情设置共用稳定的记忆挂载点和 iframe；通过 `KITCHEN_MEMORY_VIEW` 与 `archiveView.switchView()` 切换内容，不搬移或重载 iframe。内页发起的视图跳转同步外层路由。
- 人物与关系复用现有数据，但分区显示：人物与关系页在同一视图展示人物名单、档案与关系图；默认侧栏上下排列，展开到 800px 以上时并排。旧 relations 路由转向 people。剧情 iframe 内原有的剧情/人物/世界标签在嵌入模式隐藏，由外层导航统一承载。
- 人物名单位于 `archive-people` 根部，不随关系图隐藏；人物搜索过滤名单。嵌入模式的 `showPerson()` 转到外层人物路由并保留所选人物，关系页名单和关系节点均可据此打开对应档案；手机端直接显示档案，不把档案移入弹窗。
- 地图、后台演化、行动判定、模型接口共用一个 OS 挂载点；切换路由不把已加载的 OS iframe 在父节点间搬移，避免重载和状态丢失。变量面板直接嵌入共享容器。
- 嵌入模式隐藏重复标题、主题快捷按钮、关闭按钮及设备外框；设置中的外观页仅作跟随说明，保留必要的内部操作与“返回上一层”。原模块状态、存储键、宿主桥接与业务流程继续归原模块管理。
- 加载期间挂载点设置 `aria-busy`。停用功能、初始化失败、缺少聊天等情况使用面板内状态消息，提供“重试”和“前往设置”；功能开关保存后刷新生效。空数据由模块表达，例如记忆页提示“还没有剧情记录”，不能展示虚构内容。

## 窄屏

桌面默认侧栏宽度为 380–520px，参考宿主聊天区外侧空间；展开后上限 1040px。面板从顶部工具栏下延伸至窗口底部。600px 以下全宽从右侧滑入、去掉侧边框，标题和内容缩减内边距；四个一级标签分配可用宽度，二级导航保持单行并允许横向滚动。人物页在手机端直接显示人物档案，无需先经过关系图。本轮 390px 离线截图覆盖四标签、功能开关、人物名单及档案；世界二级导航超出屏宽的部分通过栏内横向滚动访问，不能把页面无横向溢出等同于所有二级入口同时可见。

## AI 回复下的摘要

- `modules/story-summary/floor-summary.js` 在已渲染的 AI 回复正文后插入原生 `details` 折叠区；用户消息、系统消息不插入。样式跟随宿主主题，正文保留换行并允许长文本折行。
- 只展示已提交记忆中可核实归属的摘要，不为显示面板另调 AI。归属以 `summaryHistory` 的真实 `batch` 记录和完成边界为依据，关联批次终点的事件摘要；不能把事件的 `_addedAt` 直接当作其来源楼层。
- 单楼批次标“第 N 楼总结”，跨楼批次标“区间总结 · 第 A–B 楼”；同一批次内的 AI 回复可能显示同一份区间摘要，不冒充逐楼独立总结。
- 无可核实摘要时显示“尚未总结”或“暂无逐楼摘要”及说明；无效记忆、越过提交边界或受源消息失效范围影响的批次不显示旧摘要。首次获得摘要时自动展开，后续文本更新保留用户的折叠选择。
- “查看剧情”携带当前楼层打开事件时间线；原消息操作区入口仍可用。聊天切换、消息编辑/重抽/删除、更多消息加载及摘要状态变化触发更新；停用或卸载时清理折叠区。

## 0.1.4 面板开放与样式统一

所有面板均可在未选择对话时打开。地图、后台演化提供无数据状态，并禁用依赖当前故事的生成、更新和属性写入。模型接口可读取、保存共享预设，判定规则可提前配置。未绑定聊天的激活仅在仍未选择聊天时有效；选择或切换聊天会使旧页面请求失效，不借用上一段聊天的数据。

模型接口、地图、后台演化和骰子通过嵌入样式映射到同一套宿主变量，字体、间距、边框、圆角和焦点样式统一；浅色或深色宿主变更即时同步。底部返回入口使用单行布局并继承正文颜色。模型表单使用中文字段名，移除旧短信样式请求与随机世界配图。

当前离线截图位于 `output/panels-preview/`：桌面模型接口、地图空状态／有数据状态、后台世界空状态／有数据状态、行动判定，以及窄屏深浅色模型接口、浅色地图和地图设置。夹具加载实际生命周期、控制器、共享配置仓库及构建后的 Vue 页面，服务器文件接口、地图／世界数据源和宿主由夹具模拟。验证未进入聊天时接口保存与规则设置、地图／世界操作禁用、进入聊天后的地图显示及主题实时切换。图中地区为测试样例；没有连接真实 Tavern、真实存档或付费模型。

## 0.1.5 原生抽屉行为

- 内容直接挂在 `#tk-topbar` 内，使用宿主 `drawer-content`、`openDrawer`、`closedDrawer`，优先调用公开的 `doNavbarIconClick`。不包含该导出的 Tavern 宿主采用兼容类切换，仍由其原生样式负责展示。
- 宿主点击外部、打开其他非固定抽屉时可以直接关闭后厨；观察 class 变化同步 aria-expanded、inert 和路由可见性。固定的 pinnedOpen 抽屉不被后厨关闭。
- 默认宽度跟随 sheldWidth；桌面“展开工作区”使用更大宽高，再次点击恢复。移动端保留底部输入区；减少动态效果的系统偏好会关闭后厨动画。
- 共享 OS 根页面没有底部导航，也没有无效返回按钮。有详情层时显示内容顶部返回；模态弹层继续使用自身关闭按钮和 Escape，避免重复导航。原世界文章页的重复返回按钮在嵌入模式隐藏。
- 点击收起、宿主自动关闭或在共享 OS 根页按 Escape 均保留已挂载的页面及其输入；切换到其他工具仍遵循原工具生命周期，不能保证跨工具切换保留未保存表单。聊天切换继续重置工作台并校验旧会话。

0.1.5 离线截图保存在 `output/native-drawer-preview/`：`api-desktop.png` 展示默认原生抽屉，`expanded-desktop.png` 展示展开工作区，`world-detail-back.png` 展示顶部详情返回，`api-mobile-light.png` 与 `map-settings-mobile-light.png` 展示窄屏和浅色主题。宿主抽屉逻辑来自本地官方快照，其余宿主状态由夹具模拟；真实 TauriTavern 联调仍待验证。

## 0.1.7 当前原生面板规范

- 后厨入口改用酒馆自带实心门形 Font Awesome 图标，与用户管理和角色管理共用字体、字号和开合状态。无自绘 SVG；不新增图标下载。
- 右侧定位不变。桌面 top: 0，展开高度充满视口；1000px 以下与原生角色管理一致，顶部保留实际工具栏高度。面板按 height/display 自上而下开合，无横向位移。
- 删除展开工作区按钮和对应状态。标题紧凑，一级与二级导航采用宿主 menu_button/active；二级导航必要时换行。
- 面板沿用宿主 tint、border 和 backdrop-filter。跟随宿主的 iframe 根部及工具页背景透明，避免多层相同半透明背景把面板叠暗。输入框等局部控件仍使用主题变量。0.1.8 已取消手动主题。
- 世界入口为局势、设定、人物、变量、地图、后台演化。人物页同时呈现名单、档案及关系图，旧 relations 路由兼容。
- world 为局势，lore 为设定，共用稳定 iframe。以属性名称只读分类：规则、地理、历史、文化、制度、物种、语言等归设定；包含当前、临时、状态、进展等变化词优先归局势；未知旧属性保留在局势。关系事实留在人物，已撤销事实不显示。分类不利用 _isState（它表示重点保留），不触发模型，也不修改原记录或存储键。
- 两个视图分别过滤内容、对象索引、计数、搜索和空状态。编辑全部记录仍打开原有共享事实编辑器，名称明确提示编辑范围。0.1.5/0.1.6 章节仅记录历史，当前行为以本节为准。

## 0.1.8 入口与动效

- `plugin-entry.js` 同步启动轻量 `kitchen-bootstrap`，挂载入口后再动态导入 `kitchen-runtime`。设置文件、模型模块和功能初始化不再阻塞按钮；运行时到达前允许打开带加载状态的面板，初始化失败保留入口和重新加载提示。扩展仍遵循宿主的加载顺序，不能保证早于宿主调度出现。
- 持续观察工具栏的创建和替换，位置正确时不搬动已有入口或 iframe；原生按钮晚到时仍保持用户管理／后厨／角色管理顺序。
- 控件进入与退出使用同一宿主动效时长及 ease-in-out；共享 OS 路由使用对称透明度过渡。同步显示隐藏的剧情、规划、下拉项及变量表单不再单向播放进入动画。宿主减少动画偏好同时作用于面板与嵌入页。
- 宿主主题改变时同步关系图配色；地图、模型接口、后台演化与骰子继续通过主题桥跟随。离线验证结果见 VALIDATION.md。
