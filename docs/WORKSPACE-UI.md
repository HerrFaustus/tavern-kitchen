# 酒馆后厨工作台界面约定

本工作台延续 SillyTavern 的原生视觉体系。参照柏宝书的顶部工具栏入口方式，以厨师帽标识后厨；此文记录宿主集成约定，不另建全局配色或字体体系。实现以 `core/kitchen-workspace.js`、`core/kitchen-embedded.css`、`style.css` 与各模块挂载代码为准。

## 宿主主题与入口

- 厨师帽为内联 SVG，使用 `currentColor`；入口沿用 `drawer` / `drawer-toggle` / `drawer-icon` 结构，插入 `top-settings-holder` 内、`persona-management-button` 之前。宿主尚未生成工具栏时等待插入；没有角色管理入口时追加到工具栏末尾。
- 文本、次要文本、强调、边框、面板背景与悬停背景分别跟随宿主的 `SmartThemeBodyColor`、`SmartThemeEmColor`、`SmartThemeQuoteColor`、`SmartThemeBorderColor`、`SmartThemeBlurTintColor`、`SmartThemeChatTintColor`。字体继承宿主；嵌入页中的默认色仅作缺失变量时的回退。
- 工作台使用边框和背景区分层次。选中标签通过强调色底线与加粗标识，键盘焦点保留可见轮廓；不以固定品牌色覆盖用户主题。

## 共享面板与导航

- 一个非模态面板承载八个标签，顺序固定为：记忆、规划、变量、地图、世界、骰子、API、设置。面板位于顶部工具栏下方，无遮罩或焦点锁定；功能内容在面板内部滚动。
- 厨师帽切换展开/收起，并维护 `aria-expanded`。首次默认进入记忆，后续展开恢复当前标签。首次展开把焦点交给当前标签；收起恢复到打开前仍存在的焦点元素，否则返回厨师帽。
- 标签使用 `tablist`、`tab`、`tabpanel` 及关联属性；当前标签是唯一 `tabindex="0"`。左右方向键循环切换并激活，Home/End 转到首尾。面板收到未被处理的 Escape 时收起；iframe 内事件不会自动冒泡到外层面板。
- 切换聊天重置并收起工作台。离开变量标签或收起面板停止其观察器。

## 模块边界与状态

- 记忆、规划与共享 OS 内容保持同源 iframe 边界，以隔离文档样式和全局变量；这不是安全沙箱。主题桥在加载后注入嵌入样式，复制上述六个宿主变量和字体，并观察宿主根节点、body 的 class/style/data-theme 变化；卸载时断开观察器。
- 地图、世界、骰子、API 共用一个 OS 挂载点。切换这些标签只更新共享内容及可访问名称，不把已加载的 OS iframe 在父节点间搬移，避免重载和状态丢失。
- 嵌入模式隐藏重复标题、主题按钮、关闭按钮及设备外框；保留必要的内部操作与“返回上一层”。变量面板直接嵌入共享容器。原模块状态、存储键、宿主桥接与业务流程继续归原模块管理。
- 加载期间挂载点设置 `aria-busy`。停用功能、初始化失败、缺少聊天等情况使用面板内状态消息，提供“重试”和“前往设置”；功能开关保存后刷新生效。空数据由模块表达，例如记忆页提示“还没有剧情记录”，不能展示虚构内容。

## 窄屏

桌面宽度上限为 1240px，左右总留白至少 32px。600px 以下面板全宽、贴底、去掉侧边框及圆角，标题和内容缩减内边距；标签保持单行并允许横向滚动。在 390px 预览中八个标签可见，设置内容自然换行。不能把该截图扩大解释为所有模块均已通过移动端验证。
