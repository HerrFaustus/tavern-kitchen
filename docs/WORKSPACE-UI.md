# 酒馆后厨工作台界面约定

本工作台延续 SillyTavern 的原生视觉体系。参照柏宝书的顶部工具栏入口方式，以厨师帽标识后厨；此文记录 0.1.2 的宿主集成约定，不另建全局配色或字体体系。实现以 `core/kitchen-workspace.js`、`core/kitchen-embedded.css`、`style.css` 与各模块挂载代码为准。

## 宿主主题与入口

- 厨师帽为内联 SVG，使用 `currentColor`；入口沿用 `drawer` / `drawer-toggle` / `drawer-icon` 结构，插入 `top-settings-holder` 内、`persona-management-button` 之前。宿主尚未生成工具栏时等待插入；没有角色管理入口时追加到工具栏末尾。
- 文本、次要文本、强调、边框、面板背景与悬停背景分别跟随宿主的 `SmartThemeBodyColor`、`SmartThemeEmColor`、`SmartThemeQuoteColor`、`SmartThemeBorderColor`、`SmartThemeBlurTintColor`、`SmartThemeChatTintColor`。字体继承宿主；嵌入页中的默认色仅作缺失变量时的回退。
- 嵌入页主按钮沿用主题派生变量：`--acc` 取正文色，反色文字 `--inv` 取面板背景，`--btn-p-hover` 混合正文色（90%）与背景，禁用背景取 `--bg3`、文字取 `--txt3`。按钮默认、悬停与禁用状态共同跟随宿主，不保留与当前主题冲突的旧反色值。
- 工作台使用边框和背景区分层次。选中标签通过强调色底线与加粗标识，键盘焦点保留可见轮廓；不以固定品牌色覆盖用户主题。

## 共享面板与导航

一个非模态面板承载三个一级标签，顺序固定为记忆、规划、设置。面板位于顶部工具栏下方，无遮罩或焦点锁定；功能内容在面板内部滚动。二级入口以 `KITCHEN_ROUTES` 为准：

| 一级标签 | 二级入口（路由） |
| --- | --- |
| 记忆 | 剧情记录（`memory`）、变量（`variables`）、地图（`map`）、世界（`world`） |
| 规划 | 剧情规划（`planner`）、行动判定（`dice`） |
| 设置 | 功能开关（`settings`）、记忆设置（`memory-settings`）、模型接口（`agent-api`） |

- 此次整理的是记忆里的设置。记忆设置归入“设置 → 记忆设置”；原记忆页设置按钮（`archive-manage-open`）在嵌入模式隐藏，助手和数据管理入口仍复用设置视图并切换到对应内部页面。剧情规划保留在独立的“规划”一级标签。
- 厨师帽切换展开/收起，并维护 `aria-expanded`。首次默认进入剧情记录，后续展开恢复当前路由；点击一级标签进入该组首项。展开时把焦点交给所属一级标签；收起恢复到打开前仍存在的焦点元素，否则返回厨师帽。
- 一级导航使用 `tablist`、`tab`，共享内容区为 `tabpanel`，并关联当前一级标签；当前标签是唯一 `tabindex="0"`。左右方向键循环切换并激活，Home/End 转到首尾。二级入口使用普通按钮及 `aria-pressed`，同组切换不重建按钮，以保留焦点。
- 面板收到未被处理的 Escape 时收起；iframe 内事件不会自动冒泡到外层面板。切换聊天重置并收起工作台。离开变量路由或收起面板停止其观察器。
- 原路由 ID 与 `openKitchenTab()` 入口继续可用，并自动选中所属一级标签；扩展设置中的“打开酒馆后厨”和消息操作区“剧情总结”入口继续保留。

## 模块边界与状态

- 记忆、规划与共享 OS 内容保持同源 iframe 边界，以隔离文档样式和全局变量；这不是安全沙箱。主题桥在加载后注入嵌入样式，复制上述六个宿主变量和字体，并观察宿主根节点、body 的 class/style/data-theme 变化；卸载时断开观察器。
- 剧情记录与记忆设置共用稳定的记忆挂载点和 iframe，通过 `KITCHEN_MEMORY_VIEW` 切换视图；切换路由不搬移 iframe。地图、世界、行动判定、模型接口共用一个 OS 挂载点，切换路由只更新共享内容及可访问名称，不把已加载的 OS iframe 在父节点间搬移，避免重载和状态丢失。
- 嵌入模式隐藏重复标题、主题按钮、关闭按钮及设备外框；保留必要的内部操作与“返回上一层”。变量面板直接嵌入共享容器。原模块状态、存储键、宿主桥接与业务流程继续归原模块管理。
- 加载期间挂载点设置 `aria-busy`。停用功能、初始化失败、缺少聊天等情况使用面板内状态消息，提供“重试”和“前往设置”；功能开关保存后刷新生效。空数据由模块表达，例如记忆页提示“还没有剧情记录”，不能展示虚构内容。

## 窄屏

桌面宽度上限为 1240px，左右总留白至少 32px。600px 以下面板全宽、贴底、去掉侧边框及圆角，标题和内容缩减内边距；三个一级标签分配可用宽度，二级导航保持单行并允许横向滚动。390px 离线预览覆盖功能开关页和聊天摘要；不能据此宣称各模块内容均已通过移动端验证。

## AI 回复下的摘要

- `modules/story-summary/floor-summary.js` 在已渲染的 AI 回复正文后插入原生 `details` 折叠区；用户消息、系统消息不插入。样式跟随宿主主题，正文保留换行并允许长文本折行。
- 只展示已提交记忆中可核实归属的摘要，不为显示面板另调 AI。归属以 `summaryHistory` 的真实 `batch` 记录和完成边界为依据，关联批次终点的事件摘要；不能把事件的 `_addedAt` 直接当作其来源楼层。
- 单楼批次标“第 N 楼总结”，跨楼批次标“区间总结 · 第 A–B 楼”；同一批次内的 AI 回复可能显示同一份区间摘要，不冒充逐楼独立总结。
- 无可核实摘要时显示“尚未总结”或“暂无逐楼摘要”及说明；无效记忆、越过提交边界或受源消息失效范围影响的批次不显示旧摘要。首次获得摘要时自动展开，后续文本更新保留用户的折叠选择。
- “查看记忆”携带当前楼层打开剧情记录；原消息操作区入口仍可用。聊天切换、消息编辑/重抽/删除、更多消息加载及摘要状态变化触发更新；停用或卸载时清理折叠区。
