# 后厨嵌入工具容器

这里仅承载地图、后台演化、行动判定和模型接口。一级／二级入口由后厨工作台管理；没有手机桌面、启动器、壁纸、设备状态栏、底部系统导航或独立窗口模式。

KitchenToolView 提供 os-stage 命名容器以及当前页面的加载、失败重试和内部返回入口。各业务页按实际可用宽度安排内容，界面始终跟随酒馆。页面切换直接替换内容；外层工作台负责抽屉开合。

宿主必须提供已连接的嵌入挂载点和明确的工具 ID。初始化只启动后台服务；不创建页面。缺少挂载点时打开请求返回未就绪。关闭工作台保留草稿，聊天切换或卸载再释放会话。

useAppLayer 继续管理业务页自己的弹层、返回栈、焦点与背景隔离。地图编辑、确认等业务弹层属于保留功能，不使用手机外壳。

验证覆盖实际构建页面、四种工具切换、业务返回、草稿保留、桌面／窄屏和慢加载；离线夹具不等同于真实宿主或模型联调。
