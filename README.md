# 酒馆后厨 0.1.4

**Based on LittleWhiteBox by biex.** 本项目基于 [小白X](https://github.com/RT15548/LittleWhiteBox) 固定提交 `e30ebadf69cd53e9fafc5f81f74b9499911f78f5`（上游版本 3.2.2）删减而来。

这是第一版开发底板：保留记忆、召回、剧情规划、变量、地图、世界后台和骰子，删除娱乐与表现功能及对应依赖。完整的“酒馆后厨”世界内核仍按外层项目的架构文档逐步实现。

## 本版保留什么

| 能力 | 当前实现 |
| --- | --- |
| 记忆 | 小白X剧情总结、分层记忆、人物与事件记录、维护与备份 |
| 召回 | 关键词检索、向量检索及召回上下文组装；Embedding 需要自行配置 |
| 规划 | 独立 ENA 规划器及上下文参考；尚非多作家编剧室 |
| 变量 | 原有变量指令、变量面板、更新与回滚；尚非内部化 MVU |
| 地图 | 层级地点、场景编辑、Three.js 三维场景与上下文投影 |
| 世界 | 原有世界分区、背景维护与注入；尚非统一世界状态 |
| 骰子 | 原有行动检定与低概率遭遇；删除付费重掷与钱包依赖，重置人物属性不收费 |
| 基础设施 | 宿主桥接、API 预设、后台任务协调、确认写入、聊天分支与保存恢复 |

点击酒馆顶部菜单栏的厨师帽，打开统一后厨工作台。一级导航为 **记忆／世界／规划／设置**：记忆保留纵向事件时间线；世界集中展示局势与设定、人物、关系、变量、地图和后台演化。规划下有剧情规划和行动判定；设置下有功能开关、记忆设置和模型接口。原有记录直接在新分区显示，无需迁移。实现与验证边界见[工作台说明](docs/WORKSPACE-UI.md)。

“设置 → 记忆设置 → 外观”新增 **跟随酒馆（默认）**，即时同步宿主配色；尚未选择主题的设备默认跟随。原先手动选择过的亮色、暗色或 Neo 主题继续保留，也可随时切回跟随模式。

未进入对话也可打开后厨各页面。模型接口与判定规则可提前配置；记忆、世界和地图显示空状态，生成地图、更新世界及编辑人物属性需选择对应对话。模型接口、地图、后台演化和行动判定统一跟随宿主主题。

角色回复下方会附上可展开、收起的总结，并提供“查看记忆”入口。直接展示已保存摘要，不增加模型调用；一个摘要覆盖多楼时明确标注区间。尚未总结或旧数据没有可核实的楼层归属时显示对应提示，不推测单楼内容。

## 已删除

绘图提供方及绘图服务端、语音、短信联系人与手机社交、钱包／银行／商店、小游戏、学习与奖励、第四墙、通用助手、电子书、独立酒馆界面、模板编辑器、沉浸模式、按钮折叠装饰、上游自动更新。混有短信与联系人逻辑的“小白板／小本本”整块移除，剧情规划由独立 ENA 模块承担。

删除包含源码、应用注册、构建入口、设置入口及无用依赖；不是仅把开关设为关闭。纯文本图片／语音标记解析器移到 `shared/legacy-markup`，用于导入旧聊天时清洗记忆，没有保留生成图片或播放语音能力。底层流式生成适配器供记忆与规划调用酒馆 API 使用。

[删除清单](docs/v1-removed-files.json)与[来源和修改说明](docs/UPSTREAM.md)可供核对。未经修改的小白X完整快照仍在外层项目的 `references/sources/RT15548__LittleWhiteBox`。

## 安装与开始

1. 在 SillyTavern 的“扩展”页面点击“安装扩展”，粘贴 `https://github.com/HerrFaustus/tavern-kitchen` 并安装。
2. 仓库已包含 `dist/` 构建产物，安装时无需运行 Node 或 pnpm；后续通过酒馆的扩展更新功能获取更新。
3. 刷新酒馆，点击顶部菜单栏的厨师帽。扩展设置里也保留“打开酒馆后厨”入口。也可下载仓库 ZIP，把完整目录以 `tavern-kitchen` 为名放到 `public/scripts/extensions/third-party/` 下。
4. 在“设置 → 功能开关”启用需要的板块并保存刷新。“设置 → 记忆设置”配置摘要和向量渠道，“设置 → 模型接口”配置世界相关模块的共享渠道；“规划 → 剧情规划”配置规划器。再按需启用地图维护、世界后台或骰子。

记忆和变量的消息快捷按钮也会打开对应标签，不再另起独立主面板。收起工作台再打开会回到上次标签；切换聊天会收起，避免把旧聊天视图误认成当前聊天。摘要自动触发、向量、地图自动维护、世界后台与骰子自动检定默认关闭，规划器也默认关闭。具体阈值与 API 由各模块设置控制。

本次没有向用户正在使用的酒馆目录部署，也没有调用付费模型。已完成离线浏览器工作台测试和桌面／窄屏截图检查，夹具代替了宿主接口和关系图依赖。宿主静态导入与资源校验使用本地固定的 SillyTavern 1.19.0 源码；1.14.0／1.18.0 的部分真实保存函数用于自动测试。**尚未完成实际酒馆浏览器及真实模型对话联调，不将本包标为稳定版。** 其他 Tavern 框架需另行验证适配。

## 数据与共存

扩展设置使用 `TavernKitchen`，记忆 IndexedDB 使用 `TavernKitchen_Memory`，后厨文件使用 `TavernKitchen_*`，OS 聊天引用与记忆本地配置也分开命名。不会自动迁移或删除旧小白X的设置、摘要或世界文件。

变量模块仍读写酒馆的局部／全局变量，部分旧指令仍沿用原语法。第一版未完成多插件共存验证；使用同一聊天时，请只让一个插件负责摘要隐藏、变量更新和规划注入。不要把本版视为已经接管世界书或 MVU：世界书依然按宿主规则参与上下文。

## 开发

需要 Node.js 24 与 pnpm 11.25.0。本次环境的系统 npm 安装不完整，因此改用 pnpm，并提交 `pnpm-lock.yaml`；没有修改系统 npm 或 Git 配置。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm build
pnpm test
pnpm check
python scripts/package.py
```

`build` 执行静态检查、类型检查、打包和宿主资源验证；`check` 还核对构建一致性、回归测试和记忆运行时。首次验证历史宿主保存函数可能下载固定提交；完整外层参考库可供离线宿主接口检查。构建过程不修改宿主源码。

测试结论及限制见 [验证记录](docs/VALIDATION.md)。运行产物在 `dist/`，开发缓存和日志在 `output/`，安装 ZIP 在 `release/`。
